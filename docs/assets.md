# Third-party assets

One line per binary asset that is not Iridesium's own: what it is, where it
came from, who made it, under which licence, and where it lives in this
repository. Nothing yet: the textures (`keystone.png`, `research_table.png`)
are Iridesium's own, drawn by hand, with `tools/make_textures.py` keeping
placeholders for any that go missing; and `sounds/ping.wav` (the Fork's
chime) came with the engine's template and is the engine's, made for it.
